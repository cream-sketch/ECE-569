\section{Motivation and Problem Definition}

Pauli-based computation (PBC) separates the easy and hard parts of fault-tolerant quantum computation. Clifford operations and Pauli measurements remain in the stabilizer domain and can be simulated efficiently by tools such as Stim/LightStim, while the non-Clifford content of a Clifford+T circuit appears as T-type magic-state resources~\cite{gidney2021stim,peres2022pbc}. Once these T resources are exposed, the practical problem is how to \emph{supply and consume them fault tolerantly}.

This project focuses on two concrete questions:
\begin{enumerate}
\item \textbf{Logical T-state preparation/injection:} how can a prepared magic state be consumed through a Clifford-and-measurement gadget to realize a logical T gate?
\item \textbf{Magic-state resource estimation:} given T-count/T-depth and a target logical error, how many distillation rounds, raw states, and potentially parallel factories are required?
\end{enumerate}
The first establishes the execution primitive; the second quantifies its cost. We do not attempt a complete PBC compiler or full surface-code architecture.

\section{Problem 1: From a Magic State to a Logical T Gate}

The T gate is $T=\mathrm{diag}(1,e^{i\pi/4})$, with magic state
\[
|T\rangle=T|+\rangle=\frac{|0\rangle+e^{i\pi/4}|1\rangle}{\sqrt{2}}.
\]
An ideal $|T\rangle$ can be generated using an ideal T gate for verification, but this is only a reference model. In a fault-tolerant implementation, the non-stabilizer resource must be prepared independently and injected into the data path.

We will implement a standard T-injection gadget:
\begin{enumerate}
\item prepare an ancilla in $|T\rangle$;
\item apply $\mathrm{CNOT}(\mathrm{data}\rightarrow\mathrm{ancilla})$;
\item measure the ancilla in the Z basis;
\item for outcome 1, apply an S correction to the data qubit.
\end{enumerate}
For outcome 0, the data becomes $T|\psi\rangle$. For outcome 1, the uncorrected branch is $T^\dagger|\psi\rangle$ up to global phase, and the Clifford S correction yields $T|\psi\rangle$. Thus, once the magic state is available, the online operation uses only Clifford gates, measurement, and classical feed-forward~\cite{bravyi2005magic}.

\textbf{Why preparation matters.} The difficult part is obtaining a sufficiently accurate logical magic state. The conventional route is magic-state distillation. A complementary route is code switching. Daguerre \emph{et al.} experimentally prepared a high-fidelity logical magic state by switching from a 15-qubit quantum Reed--Muller code to the 7-qubit Steane code~\cite{daguerre2025codeswitch}. We will not reproduce that code-switching experiment; instead, it motivates treating state preparation as an independent subsystem whose output feeds the same injection primitive.

\textbf{Experiment A -- Injection correctness.} Using Qiskit/statevector simulation, we will compare a direct ideal T gate with the $|T\rangle$-injection gadget for $|0\rangle$, $|1\rangle$, $|+\rangle$, $|-\rangle$, and random one-qubit states. We will verify both measurement branches and report output-state fidelity. A small multi-T circuit will test composition. Stim/LightStim will model the surrounding Clifford/measurement/QEC structure rather than the non-stabilizer amplitudes of $|T\rangle$ itself.

\section{Problem 2: Resource Estimation for Supplying T States}

Once T resources are identified, the next question is their production cost. We will use \textbf{15-to-1 T-state distillation} as a baseline. For sufficiently small input error $p$,
\[
p_{\mathrm{out}}\approx 35p^3,\qquad p_{r+1}\approx 35p_r^3.
\]
Ignoring rejection/retry overhead in the first-order model, each round multiplies raw-state demand by 15:
\[
N_{\mathrm{raw/out}}\approx 15^r.
\]
Thus $p_{\mathrm{raw}}=10^{-2}$ gives approximately $3.5\times10^{-5}$ after one round; a second round suppresses the error much further but raises the idealized raw-state cost from 15 to 225 states per final T state.

The estimator inputs will be T-count $N_T$, T-depth $D_T$ (or an equivalent consumption schedule), raw-state error $p_{\mathrm{raw}}$, and target error $p_{\mathrm{target}}$. An algorithm-level failure budget $\epsilon$ may define a first-order requirement such as $p_{\mathrm{target}}\leq\epsilon/N_T$. Outputs will include minimum distillation rounds, output error after each round, raw states per output, total raw states, and high-fidelity T states consumed.

We will also add a simple throughput model. Litinski's surface-code analysis shows that magic-state factories create an important \textbf{space--time tradeoff}: additional parallel distillation hardware can supply T states faster, while fewer factories reduce qubit cost but may stall T-heavy computation~\cite{litinski2019game}. Under simple timing assumptions, the estimator will therefore report factory throughput or parallelism for selected T-depth/consumption-rate scenarios.

\textbf{Experiment B -- Resource scaling.} We will sweep $N_T=10,50,100,500,1000$, representative raw-state errors such as $10^{-2}$ and $10^{-3}$, several target-error budgets, and selected T-depth scenarios. Plots will show (1) distillation rounds vs.\ target error, (2) raw states vs.\ T-count, (3) raw states vs.\ target fidelity, and (4) factory parallelism/latency vs.\ T-consumption rate.

\section{Scope, Expected Outcome, and Timeline}

The project starts after PBC or a Clifford+T analysis has exposed the T resources. We will not implement a complete PBC compiler, code-switching protocol, full lattice-surgery scheduler, or detailed physical magic-state factory.

The expected workflow is:
\[
\text{T resource identified}\rightarrow
\text{injection verified}\rightarrow
\text{required fidelity specified}\rightarrow
\text{resource cost estimated}.
\]

Minimum deliverables are: (1) T-state/injection code and correctness tests; (2) a 15-to-1 distillation estimator; (3) optional T-depth/factory-throughput estimates; (4) small Clifford+T examples; and (5) resource-scaling plots/tables.
